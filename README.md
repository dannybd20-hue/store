# מחירון הזמנות — מדריך התקנה

האתר הוא קובץ אחד (`index.html`). בלי פרטי Firebase הוא רץ במצב הדגמה. אחרי החיבור הוא אתר אמיתי שכל לקוח נכנס אליו מקישור.

## שלב 1: פרויקט ב-Firebase (כ-5 דקות)

1. נכנסים ל-https://console.firebase.google.com ולוחצים **Add project**. נותנים שם (למשל `my-store`). את Google Analytics אפשר לכבות.
2. בתפריט הצד: **Build → Authentication → Get started** → בלשונית **Sign-in method** מפעילים **Email/Password**.
3. בתפריט הצד: **Build → Firestore Database → Create database** → בוחרים מיקום (למשל `eur3`) → **Start in production mode**.
4. בתוך Firestore, לשונית **Rules**: מוחקים את מה שיש, מדביקים את כל התוכן של הקובץ `firestore.rules`, ולוחצים **Publish**.
   - אם המנהל משתמש באימייל אחר מ-`danny.b.d.20@gmail.com`, מחליפים אותו בקובץ.

## שלב 2: חיבור האתר לפרויקט

1. בדף הראשי של הפרויקט לוחצים על סמל ה-Web (`</>`), נותנים כינוי ולוחצים **Register app**.
2. יופיע קוד עם `const firebaseConfig = { ... }`. מעתיקים רק את מה שבתוך הסוגריים המסולסלים.
3. פותחים את `index.html` בעורך טקסט, ומחליפים את השורה:
   ```js
   const FIREBASE_CONFIG = null;
   ```
   בשורה עם הפרטים שלכם:
   ```js
   const FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };
   ```
4. אם צריך, מעדכנים גם את `ADMIN_EMAILS` (מתחת לזה) לאימייל של המנהל.

## שלב 3: העלאה לאינטרנט

**הדרך הקלה (בלי התקנות):** נכנסים ל-https://app.netlify.com/drop וגוררים את התיקייה. מקבלים קישור מיד.

**דרך Firebase Hosting (אם יש מחשב עם Node):**
```bash
npm install -g firebase-tools
firebase login
firebase use --add      # בוחרים את הפרויקט
firebase deploy
```
הקישור יהיה בסגנון `https://my-store.web.app`.

## שלב 4: הפעלה ראשונה

1. נכנסים לאתר ונרשמים **עם אימייל המנהל**. החשבון מאושר אוטומטית ונפתח מסך הניהול.
2. בלשונית **הגדרות**: מעלים לוגו, כותבים את שם החנות ומספר הוואטסאפ שאליו יגיעו ההזמנות.
3. בלשונית **מוצרים**: מוסיפים מוצרים עם תמונה, מחיר וקטגוריה.
4. שולחים ללקוחות את הקישור. כל לקוח נרשם (שם, אימייל, טלפון), ומופיע אצלך בלשונית **לקוחות** לאישור.

## איך זה עובד

| מי | מה הוא עושה |
|---|---|
| לקוח | נרשם → מחכה לאישור → בוחר מוצרים וכמויות → "שליחת ההזמנה בוואטסאפ" |
| מנהל | רואה קובייה לכל הזמנה → נכנס → קובע הנחה באחוזים או מחיר סופי → "אישור ושליחה ללקוח" |
| לקוח | רואה את המחיר הסופי ב"ההזמנות שלי". המנהל יכול גם לשלוח לו את המחיר בוואטסאפ בלחיצה |
| מנהל | מוריד כל הזמנה כ-PDF מעוצב (לוגו, תמונות, סכומים) או כאקסל, ואת כל ההזמנות לאקסל אחד |

## הערות

- התמונות נדחסות אוטומטית ונשמרות ישירות ב-Firestore, אז אין צורך בתוכנית בתשלום של Firebase.
- התוכנית החינמית של Firebase מספיקה לחנות קטנה-בינונית בקלות.
- לקוח שנחסם או נדחה לא יכול לראות את המחירון.
